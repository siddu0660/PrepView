## Flaw codes
Format `F-<AREA>-<WHAT>`. Use the closest existing code; add a new line here if none fits.

| Code | Meaning |
|------|---------|
| `F-NO-RESULT` | Story ends without an outcome. |
| `F-NO-METRIC` | No numbers or concrete evidence of impact. |
| `F-WE-NOT-I` | Unclear personal contribution ('we' throughout). |
| `F-RAMBLING` | Over ~2.5 minutes or lost structure. |
| `F-TOO-THIN` | Under ~45 seconds; no situational detail. |
| `F-BLAME` | Blames others or the company. |
| `F-GENERIC` | Could be anyone's answer; no specifics. |
| `F-NO-REFLECTION` | No learning or what-I'd-change. |
| `F-WEAK-SITUATION` | Low-stakes situation chosen for the competency. |
| `F-DEFENSIVE` | Defensive under a probing follow-up. |
