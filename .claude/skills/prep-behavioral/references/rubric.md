# Rubric — behavioral

Score each 0-2:

| Dimension | Looks for |
|-----------|-----------|
| Structure | S/T/A/R clearly delineated, answer first-pass under ~2.5 min |
| Ownership | specific personal actions ('I decided...'), team credit stated accurately |
| Impact | measurable result, scale, stakes |
| Reflection | learning, what would change |
| Relevance | story fits the competency asked |
| Handling follow-ups | consistent, honest, non-defensive |

## Outcome mapping
Total /12: **pass** ≥ 9 with Ownership ≥ 1; **partial** 5-8; **fail** < 5.

Hint penalty: a tier ≥3 hint (skeleton/solution) caps the outcome at `partial`. Giving up = `fail`.
