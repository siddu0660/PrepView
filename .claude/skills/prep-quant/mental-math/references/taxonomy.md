## Flaw codes
Format `F-<AREA>-<WHAT>`. Use the closest existing code; add a new line here if none fits.

| Code | Meaning |
|------|---------|
| `F-MM-CARRY` | Carry/borrow errors in add/subtract. |
| `F-MM-SIGN` | Sign errors with negatives. |
| `F-MM-DECIMAL-PLACE` | Decimal point misplacement. |
| `F-MM-FRACTION-CONV` | Wrong fraction-decimal-percent conversion. |
| `F-MM-ESTIMATION-DRIFT` | Estimate outside tolerance (rounding too aggressively). |
| `F-MM-SLOW` | Correct but over the per-question time target. |
| `F-MM-GUESS` | Wild guess (error > 50%). |
| `F-MM-METHOD-NAIVE` | Used long multiplication where a decomposition trick exists. |
